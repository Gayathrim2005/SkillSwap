# SkillSwap – Student Skill-Sharing Platform

## About the Project
SkillSwap is a web-based platform that helps students share their skills and learn new skills from others. It encourages peer-to-peer learning and collaboration among students.

## Objectives
- Encourage students to share their knowledge and skills.
- Help students learn new skills from one another.
- Create a platform for collaboration and learning.

## Features
- Simple and user-friendly interface.
- Skill-sharing among students.
- Opportunity to learn and connect with others.

## Technologies Used
- HTML
- CSS
- JavaScript

## How to Run the Project
1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in your web browser.

## Future Enhancements
- Student registration and login.
- Skill search functionality.
